# Developer Profile Card

A lightweight, responsive frontend component showcasing a personal profile card for a Web Developer & Chemical Engineering student. Built using semantic HTML5 and clean modern design principles.

## Tech Stack
- **HTML5** - Structuring page content natively.
- **CSS3** - External styles linked via `style.css`

## Project Structure
```text
├── public/
│   ├── ches-logo.png    # Association / Department logo banner
│   └── photo.jpg        # User profile display picture
├── index.html           # Main markup file
└── style.css            # Component design layout
```

## Key Features
- **Responsive Architecture:** Includes viewport meta optimization for flawless rendering across desktop, tablets, and mobile smartphones.
- **Semantic Structure:** Designed using modern CSS class definitions facilitating easy structural isolation.
- **Accessible Design:** Features descriptive `alt` tags on all images to aid screen readers and provide fallback states during slow network connectivity.

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Place your custom imagery inside the `public/` directory matching the filenames (`photo.jpg` and `ches-logo.png`).
3. Open `index.html` directly in any web browser to preview locally.
